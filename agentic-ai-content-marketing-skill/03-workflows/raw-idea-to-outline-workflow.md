# Raw Idea To Outline Workflow

## Mục Đích

Chuyển ý tưởng thô thành outline Marketing.

## Input

- Ý tưởng thô.
- Mục tiêu nội dung.
- Audience nếu có.
- Nền tảng đăng nếu có.

## Process

1. Tóm tắt ý tưởng.
2. Xác định mục tiêu.
3. Xác định audience.
4. Tìm pain point.
5. Brainstorm nhanh bằng 5W-1H.
6. Choose layout from `02-frameworks/content-layout-systems/00-layout-system-control/layout-selection-matrix.md`.
7. Validate layout type and confidence with `layout-taxonomy.md`.
8. Chọn hook.
9. Build the Marketing outline 5 phần using the selected layout.
10. QA layout fit with `07-quality-gates/layout-fit-checklist.md`.
11. Kiểm tra logic outline.

## Output

- Target audience.
- Pain point.
- Insight.
- Selected layout.
- Layout type.
- Marketing outline 5 phần.
- Ghi chú ý cần bổ sung.
