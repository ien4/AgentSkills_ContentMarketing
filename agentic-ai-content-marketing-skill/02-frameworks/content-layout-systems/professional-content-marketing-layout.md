## Definition

This is a meta-framework / professional content planning framework. It describes how to think about content structure professionally: choose a validated layout system, expand the outline with supporting thinking tools, then write toward a clear Marketing goal.

It is not a standalone content arrangement pattern.

## Core Principle

Professional content starts with strategic planning: goal, audience, layout choice, outline, idea expansion, writing, and QA. It should guide planning quality, not replace `layout-selection-matrix.md`.

## Goal

- Check whether content planning is professionally structured.
- Coordinate audience, goal, outline, CTA, logic, platform fit, and selected layout.
- Help agents avoid copying formulas without understanding the underlying layout.
- Act as a meta-check after a validated layout has been selected.

## When To Use

- When auditing whether content planning is complete.
- When checking whether a draft has audience, logic, CTA, platform fit, and selected layout.
- When coordinating several resources: outline, 5W-1H, layout system, and quality gates.
- When teaching or documenting professional content planning principles.

## When Not To Use

- Do not use as the main layout in `/post` before selecting a validated layout system.
- Do not use instead of moc xich, tong phan hop, quy nap, or liet ke.
- Do not use instead of a workflow file.
- Do not use instead of a template for Facebook, carousel, or video.
- Do not use instead of a quality gate; use it before or alongside quality gates.

## Professional Planning Flow

Step 1: Clarify content goal, audience, pain point, and insight.

Step 2: Select a suitable layout from `layout-selection-matrix.md`.

Step 3: Validate layout type, status, and confidence in `layout-taxonomy.md`.

Step 4: Use 5W-1H only as an idea-expansion tool when needed.

Step 5: Build the Marketing outline 5 phần using the selected layout.

Step 6: Write, QA, and adjust for platform fit.

## Content Flow

Goal -> audience -> selected layout -> idea expansion -> Marketing outline 5 phần -> content -> QA.

## Mini Example

Topic: course content post.

- Goal: persuade beginners to stop writing without outline.
- Select layout: quy nap if the conclusion should come after evidence.
- Use 5W-1H: clarify who struggles, what pain appears, why outline matters.
- Build outline: title, opening description, body, conclusion, CTA.
- QA: layout fit, logic, CTA and platform fit.

## Common Mistakes

- Treating this file as the selected layout.
- Skipping matrix and taxonomy.
- Mixing 5W-1H with layout systems.
- Using a platform template before choosing the content structure.
- Scoring professionalism without checking layout fit.

## Checklist

- [ ] Has a concrete content goal been identified?
- [ ] Has a validated layout been selected before writing?
- [ ] Has taxonomy been checked for type, status, and confidence?
- [ ] Is 5W-1H used only for idea expansion?
- [ ] Is the Marketing outline 5 phần built from the selected layout?
- [ ] Has layout-fit QA been run?

## Difference From Similar Layouts

- Compared with layout systems: this file coordinates planning; layout files define how ideas are arranged.
- Compared with workflows: workflows prescribe execution steps for a task; this file gives a professional planning lens.
- Compared with templates: templates define output formats; this file helps choose and validate the structure before templating.
- Compared with quality gates: quality gates pass/fail the output; this file helps prepare the plan before QA.
