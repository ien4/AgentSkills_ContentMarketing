# Raw Idea To Facebook Post Workflow

## Mục Đích

Chuyển ý tưởng thô thành bài Facebook có cấu trúc Marketing.

## Input

- Ý tưởng hoặc brief.
- Audience.
- Mục tiêu bài viết.
- Tone of voice.
- CTA mong muốn.

## Process

1. Hiểu brief.
2. Xác định audience và pain point.
3. Phân tích 5W-1H.
4. Choose layout based on content goal.
5. Validate layout type and confidence with `layout-taxonomy.md`.
6. Build Marketing outline 5 phần using the selected layout.
7. Viết bản nháp.
8. Kiểm tra CTA.
9. QA layout fit, logic và độ phù hợp nền tảng.

## Output

- Selected layout.
- Layout-fit notes.
- Marketing outline 5 phần.
- Bài Facebook hoàn chỉnh.
- CTA.
- QA checklist.
